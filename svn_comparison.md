1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

Git: ветка — это просто ярлычок-указатель на коммит (40 символов). Создать её — мгновенно, ничего не копируется.

SVN: ветка — это реальная копия папки на сервере. Создавать и переключаться тяжелее.


2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN — централизованная система: коммит сразу уходит на сервер и создаёт там ревизию. Без сети коммитить некуда — локальной истории у клиента нет. В Git наоборот: коммит делается локально, интернет нужен только для push.


3. Когда SVN всё ещё лучше Git?

- Много больших бинарников (графика, видео, 3D) — SVN не тянет всю историю, Git раздувается.
- Жёсткий контроль доступа — в SVN проще раздать права по папкам, у каждого нет полной копии репозитория.
- Простота для нетехнических людей — один сервер, одна история, без веток и rebase.
- Старые проекты, где всё уже работает и миграция не нужна.
- Частичная выкачка — в SVN легко скачать только нужную папку из огромного репозитория.
